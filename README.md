# E-commerce Order Profit Analysis

## Project Overview
This project analyzes e-commerce order data using Python to identify sales trends, profitable product categories, city-wise revenue, and the relationship between discounts and profit.

## Objectives
- Calculate total revenue and profit.
- Identify the most profitable product category.
- Analyze city-wise revenue.
- Study the relationship between discounts and profit.
- Identify monthly revenue trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset Information
- Total cleaned records: 248
- Total columns: 12
- Data type: E-commerce order data

## Key Findings
- Total Revenue: ₹23,44,995.85
- Total Profit: ₹1,66,085
- Total Orders: 248
- Average Order Value: ₹9,455.63
- Most Profitable Category: Fashion
- Highest Revenue City: Delhi
- Highest Revenue Month: April
- Discount vs Profit Correlation: -0.58

## Project Structure
- `data/raw/` – Original dataset
- `data/processed/` – Cleaned dataset
- `notebooks/` – Jupyter Notebook analysis
- `requirements.txt` – Required Python libraries

## How to Run
1. Clone or download this repository.
2. Install the required libraries using:

   `pip install -r requirements.txt`

3. Open `notebooks/ecommerce_analysis.ipynb`.
4. Run the notebook cells.

## Conclusion
This project demonstrates how Python can be used to clean, analyze, and visualize e-commerce data to generate meaningful business insights.
